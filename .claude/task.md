**Промт для Claude Code:**

Ты — опытный разработчик на Golang, специализирующийся на создании архитектурных решений для AI-агентов. Твоя задача — написать код модуля агента в приложении на Go, который будет полностью соответствовать следующим требованиям:

1. **Архитектура модуля**:
   - Создай модуль как отдельный пакет (package) с четко выделенными интерфейсами и структурами данных
   - Используй принципы SOLID и проектирования через интерфейсы (interface-based design)
   - Организуй код в логические подпакеты (например: `llm`, `filesystem`, `database`, `web`, `core`)
   - Модуль должен быть независимым и легко интегрируемым в существующее Go-приложение

2. **Интеграция с LLM (OpenAI API)**:
   - Реализуй поддержку протокола OpenAI (ChatCompletion и Embeddings API)
   - Создай пакет `llm` с абстракцией над LLM-провайдерами
   - Поддержка конфигурирования через конфигурационный файл или переменные окружения
   - Реализуй поддержку разных моделей и токенов

3. **Работа с файловой системой**:
   - Реализуй функции чтения и записи файлов: `ReadFile`, `WriteFile`, `ListFiles`
   - Создай интерфейс для работы с файлами, чтобы его можно было легко подменить в тестах

4. **Работа с базой данных**:
   - Реализуй возможность выполнять запросы к БД через сервисный слой приложения
   - Используй уже существующие сервисы приложения для работы с БД
   - Обеспечь интеграцию с ORM или SQL-запросами

5. **Поиск в интернете (web scraping / search)**:
   - Реализуй возможность выполнять поисковые запросы в интернете
   - Маскируй запросы под браузер: используй User-Agent, заголовки, и другие приёмы для избежания блокировок
   - Поддержи как обычные HTTP-запросы, так и headless браузер (например, через Puppeteer или аналоги)
   - Реализуй парсинг результата поиска и извлечение нужной информации

6. **Интеграция и расширяемость**:
   - Все компоненты должны быть легко расширяемыми через паттерны "strategy" или "middleware"
   - Предусмотри возможность подключения новых провайдеров LLM, способов доступа к файлам, БД, или веб-поиска

7. **Код должен включать**:
   - Основную структуру модуля с интерфейсами
   - Примеры типов данных и методов
   - Конфигурационные структуры
   - Интерфейсы для всех компонентов
   - Примеры реализации основных функций (без сложной логики, только структура)

Напиши код модуля агента в одном файле или нескольких файлах, организованных в пакет, без использования сторонних библиотек, кроме стандартных. Код должен быть готов к интеграции в реальное приложение на Go и соответствовать современным практикам разработки.
Не забудь описание в README.md
